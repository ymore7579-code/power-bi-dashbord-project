# 📊 Sales Dashboard & Forecasting – Power BI

## 📌 Project Overview

This project is an interactive **Sales Analytics Dashboard built using Microsoft Power BI**.

The dashboard helps analyze sales performance, profit, orders, customers, products, regions, and sales trends. It also includes a **Forecasting** page to identify potential future sales trends.

The project demonstrates practical skills in **Data Analysis, Data Visualization, Power BI, DAX, Data Modeling, and Business Intelligence**.

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Track important business KPIs
- Identify top-performing products and categories
- Analyze sales by region and location
- Understand sales trends over time
- Analyze customer and order performance
- Compare sales and profit
- Create an interactive dashboard using slicers
- Forecast future sales trends

---

## 📊 Dashboard Pages

### 1. Main Dashboard

The Main Dashboard provides an overview of business performance.

### Key KPIs

- 💰 Total Sales
- 📈 Total Profit
- 🛒 Total Orders
- 📦 Total Quantity Sold
- 👥 Total Customers
- 📊 Profit Margin

### Visualizations

- Sales by Category
- Sales by Product
- Sales by Region
- Sales Trend Over Time
- Profit Analysis
- Top Products
- Geographic Sales Analysis
- Interactive slicers and filters

---

### 2. Forecasting Dashboard

The Forecasting page is used to analyze historical sales trends and estimate future sales performance.

It helps answer questions such as:

- What is the current sales trend?
- Is sales performance increasing or decreasing?
- What could future sales look like?
- What are the expected sales values based on historical trends?
